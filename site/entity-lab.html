The helpers check embedding model, revision, preprocessing, normalization and dimensions. Missing fields, incompatible spaces, and zero vectors produce unknown. Scores use binary64 floating point. The demo vectors are illustrative; this page does not generate embeddings.

Code runs in a fresh browser worker with a 20-second limit. These are trusted user functions with normal worker capabilities. No Isabelle theorem is attached to entity comparisons.
