The reference calls the existing Quantity.kernel (MassOf …), exported by Isabelle to OCaml. mass_from_volume relates an exact result to its dimensions and mass = density × volume. The source module and build record are available below.

The OCaml/JSON interface, model adapter, and browser toolchain are tested components. Your edited kernel has no proof attached. Z3 checks the particular formalized claims; neither a passing comparison nor a theorem establishes that the sample has the assumed density.

An arbitrary user comparison is evaluated on these concrete inputs. It is not translated into a universal Z3 definition, and a successful match does not merge entity identities.
